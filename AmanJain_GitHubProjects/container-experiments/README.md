## Setup Instructions
1. Install Docker on your system.
2. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/container-experiments.git
   cd container-experiments
   ```
3. Build and run containers using the provided Dockerfiles or scripts.

## Docker Commands Used
