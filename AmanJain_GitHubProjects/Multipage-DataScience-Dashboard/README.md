## How to Run
1. Set up a Python virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # or venv\Scriptsctivate on Windows
   ```
2. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the app:
   ```bash
   python app.py
   ```
